# 보호자 음성→글자 데모 v4

보호자의 한국어 음성을 텍스트로 표시하는 독립 DEV 화면입니다. 원장 화면 미리보기는 같은 브라우저에만 저장되며 실제 동물병원이나 원장 기기로 전송하지 않습니다.

## 변경

- 공통 `../shared/speech-controller.js`를 사용합니다. 사용자 시작 후 앱은 무음 타이머로 듣기를 끝내지 않고, 엔진이 실제 종료된 경우에만 직렬 재연결합니다.
- 중간 문장은 같은 발화 위치에서 교체하고 확정 결과는 한 번만 반영합니다. 같은 결과 배열 반복, 즉시 반복된 결과 슬롯, 일부 누적 가설을 방어합니다. 새 발화로 확인되는 의도적인 반복은 보존합니다.
- 시작 중 중복 인식기를 만들지 않으며, 글자 삭제 전 이전 콜백을 무효화합니다. 탭 이동·페이지 숨김 시 마이크를 정지합니다.
- 보내기는 마지막 결과 반영을 기다린 후 한 번의 클릭으로 미리보기에 추가합니다. 수동 입력과 음성 인식 후 직접 고친 글을 보존합니다.
- 기존 초안·미리보기의 localStorage 키를 유지합니다. 긴 인식문을 5,000자로 몰래 잘라내지 않습니다.

## 처리 범위

이 앱은 MediaRecorder 등 녹음 파일 생성 API를 사용하지 않고 오디오 파일을 저장하거나 직접 업로드하지 않습니다. 브라우저 음성인식 서비스의 원격 처리는 별개입니다. 한국어 로컬 모델 사용 가능과 `processLocally` 지원을 확인한 세션만 기기 내 처리로 표시하며, 모델을 자동 설치하지 않습니다.

Android의 음성 서비스·브라우저 버전에 따라 세션 종료와 시스템 표시음이 발생할 수 있습니다. 모든 기기의 무중단 듣기·시스템 음소거를 보장하지 않습니다. S10용 네이티브 온디바이스 연결은 이 웹 변경에 포함되어 있지 않습니다.

## 검증

2026-11-22 가짜 인식기/DOM 검사: 중간 문장 갱신, 확정 결과 재통지, 즉시 반복 슬롯, 삭제 후 늦은 결과, 마지막 결과 반영 후 단일 전송, 원장 탭으로 전환 시 정지, 기존 초안·미리보기 보존, 직접 입력·인식 후 수정·탭 왕복 후 보내기. 실제 갤럭시 S10 마이크는 미검증입니다.
