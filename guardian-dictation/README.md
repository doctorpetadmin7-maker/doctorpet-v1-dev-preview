# 닥터펫 보호자 음성→글자 데모

기존 doctorpet-dictation-demo는 참고 링크로 제공되었지만 현재 실행 원본을 직접 가져오지 못했습니다. 이 모듈은 독립된 실시간 한국어 음성입력 테스트 화면입니다.

## 기능
- 브라우저 SpeechRecognition (ko-KR): interimResults + continuous 옵션(지원 범위 내)
- 말한 글자를 입력창에 실시간 표시, 중간/최종 결과 중복 합산 방지
- 사용자 직접 수정, 글자 복사, 스마트폰 공유 메뉴로 텍스트 전달 가능
- localStorage에 초안 자동 저장, 새로고침 복원, 삭제
- 동일 기기의 원장 화면 **미리보기**. 기존 원장–보호자 간 실제 메시지 서버 전송과는 분리
- 녹음파일 저장/MediaRecorder/AudioWorklet/오디오 업로드 사용하지 않음
- 반복 시작/종료음 방지를 위해 자동 재시작하지 않음

## 한계 및 다음 연결
Android Chrome의 SpeechRecognition.continuous 옵션은 설정 가능하지만 실제 연속 처리가 지원되지 않아 인식이 빨리 종료될 수 있습니다. 10초 이상 무음으로 완전한 연속 청취 보장은 이 방식만으로 할 수 없습니다. 더 안정적인 연속 인식에는 브라우저 마이크 스트리밍과 서버 기반 Realtime STT 연결이 필요하며, API 키는 서버에만 둡니다.

원장에게 진짜로 보내는 기능은 기존 닥터펫 채팅 서버의 인증된 sendMessage({roomId,text}) 경로에 연결해야 합니다. 현재 **미리보기 전송은 동일 브라우저**에만 저장됩니다. 공개 시 정보보호 동의·저장정책을 검토하세요.

## 검수
브라우저 모의 SpeechRecognition: interim→final, 중복 결과 0, 인식 종료 후 리스너 재시작 0, 초안 복원, 수정 및 전송 미리보기, 새로고침 후 재조회, JS 오류 0 (2026-11-22). 실제 갤럭시 마이크는 미검수.
