# 닥터펫 수의계 뉴스 R5.4 — 사진 100칸 + 소개글 2줄 연결 후보 / 1번 인계
기준: 2026-11-09 KST. **독립 디자인 후보·비공개 개발 실험**. GitHub main, 공용 032, 기존 DEV 뉴스 API, DB, Storage, 수집기, 운영 서버는 변경하지 않음.

## 대표 요구 사항
뉴스 카드: **사진 + 제목 + 날짜 + 2줄 소개글**, 매체 선택, 검색, 최신순, **100건씩 페이지 넘김**. 실제 사진·내용이 미확보된 기사는 준비 상태를 분명히 표시.

## 3번 신규 구현
- 후보 HTML: `vet-news/staging/r54-licensed-media-ready-ui.html`.
- 기존 승인 R4.5 레이아웃/뉴스 안전 API 파서 유지. 카드 사진에는 해당 기사 ID·sourceId·원문 링크와 정확히 일치하는 **별도 등록 사진**만 연결.
- 이미지 파일은 같은 출처 `./licensed-media/<파일명>.webp|jpg|png`의 안전한 파일명만 허용. 외부 언론사 원본 이미지 URL은 사용하지 않음.
- 원문 소개글/본문을 임의 합성하지 않음. 별도로 작성·검증된 원문과 다른 **자체 소개글**이 있을 때만 2줄 레이아웃에 표시. 미등록이면 '기사 소개글이 아직 등록되지 않았습니다'라고 구분.
- `LICENSED_ARTICLE_MEDIA`는 **현재 빈 객체**, 현재 실제 사진/소개글 연결 **0건**. 권리 플래그 문자열은 *클라이언트 표시 필터*이지 법적 이용 허락을 증명하지 않음. 실제 본 서비스 공개 전에 담당자 서면 확인·서버 검증/승인 워크플로가 필요.
- 표시한 카드의 이미지 로딩 실패 시 사진 자리로 되돌리며, 소스에 없는 다른 기사의 이미지로 바꾸지 않음.
- '등록된 사진 x/N건 · 등록된 소개글 y/N건' 상태를 실제 연결 상태에 맞춰 표시.

## 현재 보관 및 공개 실적
- DEV 원본 기사: 데일리개원 64, 데일리벳 비공개 23, 해피펫 비공개 2 (총 89).
- 대표사진 URL 기록은 **17건** (데일리개원 2·데일리벳 13·해피펫 2)이며, 원본 사진 **100장 확보/재게시 허락/실제 표시**를 뜻하지 않음.
- 목표 사진 100장에 비해 원본 사진 URL 기록도 83건 부족하며, 현재 공개 후보 RSS 기사도 64건이라 한 페이지에 100개 실사진을 채울 100개 공개 적격 기사 자체가 확보되지 않음. 수집 금지 출처는 보충용으로 재개하지 않음.
- 사진 0장/소개글 0건 실제 연결로 표시해야 함. 로컬 합성 100건 테스트는 **실제 기사 100건 공개·사진 100장 등록이 아님**.
