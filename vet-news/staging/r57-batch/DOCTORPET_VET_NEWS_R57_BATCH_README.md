# 닥터펫 수의계 뉴스 R5.7 — 100건 사진·소개글 일괄 등록기 (보안·복구 보완)

**상태: 로컬 검토 전용 / 외부 게시 0건 / 새로운 사진·기사 확보 0건.** R5.5를 기반으로 기존 수집·공용 홈페이지·운영 서버를 변경하지 않고 개선한 패키지입니다.

## 구성

- `doctorpet_vet_news_r57_batch_media_builder.py`: 안전한 DEV API 스냅샷, 사진 사용권 CSV, 사진 파일을 검증하고, 독립된 **검토용 HTML 파일**만 만듭니다.
- `doctorpet_vet_news_r57_batch_media_tests.py`: 임시 가상 이미지 100개 및 16개 등록 실패·9개 응답 변조 실패·동시 저장 등 자동시험. 실제 기사 이미지·본문 접근 없음.
- `doctorpet_vet_news_r55_approved_media_template.csv`: 빈 입력 양식. 승인 항목은 별도 확인하기 전까지 입력하지 마십시오.

## R5.7에서 강화한 항목

1. 기존 API의 `version=2`만 보는 것이 아니라 **제한 출처의 상태·공개 건수 0·후보 보류·사진/소개글 보류 필드**를 필수 확인합니다. 이 중 하나라도 누락 또는 변조되면 전체 출력 중지.
2. 사진 확장자/파일명·파일 해시 외에 PNG의 필수 청크·CRC·크기, JPEG의 시작·종결, WebP RIFF 선언 길이와 포맷을 검사합니다. 브라우저 실제 디코딩이 아닌 기본 컨테이너 무결성 검사이며, 실기기 로딩 검수는 여전히 필요합니다.
3. 두 실행이 같은 파일에 저장을 시도해도 결과 파일을 덮어쓰지 않는 **원자적 무덮어쓰기** 방식을 적용했습니다.
4. 기사 ID·URL·매체 일치, 동일 기사 URL 중복, 로컬 파일 위치, 사진 권리 참조, 권리 기한, 자체 작성 소개글 검수 기록을 확인합니다. 단, 문자열로 된 증빙 참조는 **실제 이용 허락의 증거가 아닙니다**. 검수 담당자가 권리 문서 원본을 별도 확인해야 합니다.
5. 최종 HTML에는 사용권 증빙 ID/파일 SHA를 싣지 않고, 기사별 사진 파일명·출처 표기·검수된 소개글만 포함합니다.

## 설치/작업 순서

1. GitHub Draft PR #2 `vet-news/staging/r55-licensed-media-attributed-ui.html`의 **R5.6에서 `img-src 'self'`로 고친 최신 원본**을 내려받아 같은 작업 폴더에 둡니다. `img-src 'none'`인 오래된 사본은 사용 금지입니다.
2. DEV 안전 뉴스 API `doctorpet-vet-news-release-data`의 **허용 메타데이터만 포함된 실제 JSON 스냅샷**을 로컬에 보관합니다. 스냅샷은 GitHub나 공용 화면에 게시하지 않습니다. 예전 test fixture는 R5.7 필수 권리 필드를 포함하지 않아 정상적으로 거절됩니다.
3. 소유·라이선스를 개별 검수한 파일만 `<작업폴더>/licensed-media/`에 저장합니다. 실제 이용권 증빙문서는 공개 폴더 밖에서 관리합니다.
4. 빈 CSV에 승인된 기사 ID/sourceId/기사 원문 URL/사진 파일·SHA256·권리근거·기한·출처 표기와 독자 소개글 검수 참조를 채웁니다. 승인되지 않은 항목은 빈칸으로 둡니다.
5. 다음을 실행합니다(표준 Python 3, 네트워크 연결 불필요).

```bash
python3 doctorpet_vet_news_r57_batch_media_tests.py
python3 doctorpet_vet_news_r57_batch_media_builder.py \
  --csv doctorpet_vet_news_r55_approved_media_template.csv \
  --snapshot dev-news-safe-snapshot.json \
  --media-dir ./licensed-media \
  --template r55-licensed-media-attributed-ui.html \
  --output r57-news-review-only.html
```

도구는 `r57-news-review-only.html`이라는 **새 후보만** 만듭니다. 이미 파일이 있으면 덮어쓰지 않고 중단합니다. 결과물은 게시 버튼/배포 기능이 없으며 1번 전략실의 최신 공용 원본·같은 시점 복구본 접합과 실PC/실휴대폰 검수, 대표님의 공개 결정을 대신하지 않습니다.

## 재현 검수 (가상 데이터)

- 사진·소개글 100쌍 일괄 연결 **100/100 PASS**.
- 불완전한 권리 기록·파일명·교차 기사·손상된 사진 등을 **16/16 거부**.
- 제한 출처 해제·비공개 건수 누출·후보 공개·사진/본문 노출 등의 응답 변조 **9/9 거부**.
- 기존 결과 재생성 거부 및 동시 2개 저장 요청에서 1개만 성공, 나머지 안전 차단 **PASS**.
- 빈 승인 데이터, 사진만 등록, 소개글만 등록 **PASS**.
- 실제 뉴스 사진·본문·소개글 공개 또는 라이선스 확보 **0건**.
