# 내 일정 비서 v4

기존 공개 DEV 데모의 일정·초안·등록 전 후보 저장 키를 유지한 화면 개선입니다. 닥터펫 운영 서버·DB·회원 데이터는 변경하지 않습니다.

## 동작

- 상단의 마이크와 인식문, 높이가 고정된 가로 날짜 카드, 하단 월간 달력을 한 페이지에 배치합니다.
- 카드에서 날짜·시간·내용을 수정하고 체크한 후보만 최종 등록합니다. 미선택 후보와 기존 일정은 보존합니다.
- 후보 ID를 등록 일정 ID로 유지하여 등록 재시도 시 중복을 막습니다. 기존 후보 데이터에는 체크 상태를 기본 적용합니다.
- 음성 확정 결과만 후보로 추가합니다. 중간 인식문은 같은 자리에 갱신하고, 최종 등록 중에도 계속 듣기 의도를 유지합니다.
- 오늘·내일·이틀 뒤·10일 뒤·절대 날짜 등을 기기 현지 날짜 기준으로 해석합니다. 화면에서 실제 날짜를 확인한 뒤 등록합니다.
- 아래 달력은 이 데모의 달력입니다. 휴대폰 기본 캘린더에는 별도의 .ics 가져오기가 필요합니다.

## 음성인식

공통 구현은 `../shared/speech-controller.js`입니다. 시작 버튼으로 한 번 마이크를 켜면 앱은 무음 타이머로 종료하지 않습니다. 실제 엔진이 끝났을 때만 직렬 재연결합니다. 명시적 종료, 페이지 숨김, 권한 오류에서는 재개하지 않고, 빠른 반복 오류에는 제한된 재시도 후 상태를 표시합니다.

지원 여부를 런타임에 확인하며, 한국어 로컬 모델이 `available`이고 해당 인식기에 `processLocally`가 있는 경우에만 기기 내 모드를 선택합니다. 미지원 시에는 기존 브라우저 인식으로 표시합니다. 모델을 자동 설치하지 않습니다.

갤럭시 S10의 네이티브 Android 온디바이스 엔진이나 ML Kit를 설치·연결한 버전은 아닙니다. 웹 API만으로 모든 기기의 무중단 청취나 OS 시작·종료음 제거를 보장할 수 없습니다. 앱에는 녹음 파일 생성·저장·직접 오디오 업로드·알림음 재생 코드가 없습니다. 브라우저 제공 서비스가 원격으로 음성을 처리하는지는 별개입니다.

## 검증 범위

2026-11-22: 가짜 인식기·가상 시계로 침묵 유지, 엔진 종료 후 재연결, 정상 무음 종료 반복, 빠른 오류 차단, 같은 결과/누적 결과 방어, 사용자 종료·페이지 숨김·늦은 콜백 무효화, 런타임 로컬 모드 선택을 검사했습니다. DOM 테스트로 기존 데이터 유지, 체크 등록, 수정 취소, 여러 차례 등록, 음성 중 최종 확인, 중복 콜백·늦은 콜백 처리를 확인했습니다.

실제 삼성 갤럭시 S10 마이크 입력·한국어 인식 품질·시스템 알림음은 미검증입니다. 모의 입력 검사를 실기기 검사로 취급하지 않습니다.
